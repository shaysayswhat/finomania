# Finomania command reference

Commands are typed in the Command window (Enter runs the current line), written in program files (`.fprg`) or generated by the dialogs. Options go in parentheses right after the command name; `name.method` calls a view or procedure of an object.

## Workfile

| Command | Syntax | Description |
|---|---|---|
| `expand` | `expand end_date` | Extend the workfile range (for out-of-sample forecasting). |
| `export` | `export "path" [series...]` | Export series to CSV / Excel / Stata / Parquet. |
| `fetch` | `fetch(source=yahoo&#124;fred, start=2010-01-01, end=, field=adjclose) symbols...` | Download data from Yahoo Finance or FRED into the workfile (creates one if needed). |
| `import` | `import(date=col, id=col, freq=m, sheet=) "path"` | Import CSV / Excel / Stata / Parquet. Dates and panel structure are detected automatically. |
| `rndseed` | `rndseed n` | Seed the random number generator (nrnd, rnd). |
| `smpl` | `smpl start end [start end ...] [if condition]  &#124;  smpl @all` | Set the current sample. |
| `wfclose` | `wfclose [name]` | Close a workfile. |
| `wfcreate` | `wfcreate(name) freq start end  &#124;  wfcreate u n  &#124;  wfcreate(panel=N) freq start end` | Create a new workfile. freq: a, s, q, m, w, d5, d7 or u (undated). |
| `wfopen` | `wfopen "path"` | Open a Finomania workfile (.fwf) or a data file as a new workfile. |
| `wfsave` | `wfsave ["path"]` | Save the active workfile (.fwf). |
| `wfselect` | `wfselect name` | Make another open workfile active. |

## Objects

| Command | Syntax | Description |
|---|---|---|
| `copy` | `copy source destination` | Copy an object. |
| `delete` | `delete name [name...] (wildcards * ? allowed)` | Delete objects. |
| `equation` | `equation name.method(options) specification` | Declare and estimate a named equation, e.g. equation eq1.ls y c x |
| `freeze` | `freeze(name) command_or_view` | Store the output of a view as a table / graph object. |
| `group` | `group name ser1 ser2 ...` | Create a group of series. |
| `matrix` | `matrix name = @cov(group) &#124; @cor(group)` | Create a matrix from a group statistic. |
| `name` | `name newname` | Name the last untitled estimation so it is stored in the workfile. |
| `print` | `print name` | Print an object's output. |
| `rename` | `rename old new` | Rename an object. |
| `show` | `show name &#124; show ser1 ser2 ...` | Open an object (several series open as a group). |
| `var` | `var name.ls lag1 lag2 y1 y2 [@ c x]  &#124;  var(lags=2) y1 y2 [@ exog]` | Estimate a vector autoregression. |

|---|---|---|

## Expressions

Series expressions follow EViews conventions: `x(-1)` lag, `x(1)` lead, `d(x)`, `d(x,n,s)`, `dlog(x)`, `log`, `exp`, `abs`, `sqrt`, `^` power, `=` / `<>` comparisons, `and` / `or` / `not`.

| Function | Meaning |
|---|---|
| `@mean, @sum, @stdev, @var, @vars, @min, @max, @median, @quantile(x,q), @obs, @nas, @skew, @kurt` | Scalar statistics over the current sample |
| `@cor(x,y), @cov(x,y), @covs(x,y)` | Correlation / covariance |
| `@movav(x,n), @movsum, @movstdev, @movvar, @movmin, @movmax, @ewma(x,lambda)` | Moving-window statistics |
| `@cumsum, @cumprod, @cummax, @cummin` | Cumulative functions |
| `@pch(x), @pcha(x), @pchy(x)` | Percent change: one period, annualised, year-on-year |
| `@recode(cond,a,b), @iif, @nan(x,y), @isna(x)` | Recoding and missing values |
| `@trend, @obsnum, @year, @quarter, @month, @day, @weekday, @seas(k), @crossid` | Deterministic / calendar |
| `@demean, @detrend, @standardize, @meansby(x,g)` | Transformations |
| `nrnd, rnd, @rtdist(df), @rchisq(df)` | Random numbers (seed with rndseed) |
| `@cnorm, @dnorm, @qnorm, @logit, @log10, @round, @floor, @ceil, @inv` | Math |
| `eq1.@r2, eq1.@aic, eq1.@logl, eq1.@coefs(i), eq1.@stderrs(i), eq1.@tstats(i)` | Results of estimated objects |
| `!x = 1, %s = "text", {!x}, {%s}` | Program variables and text substitution |
| `for/next, if/then/else/endif, while/wend, exitloop, stop` | Program control flow |
